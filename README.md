# NAS Shell 0.6 Demo

Публичная демонстрация интерфейса NAS Shell 0.6: https://akva24ru-ai.github.io/nas-shell-demo/.

Доступны локальное DEMO-сканирование оборудования, подробный отчёт, импорт и экспорт диагностического JSON, а также пятишаговый мастер с выбором модели Synology и версии DSM и экспортом проекта конфигурации. Все результаты явно помечены DEMO; совместимость не подтверждается.

Страница выполняется в браузере и не обращается к NAS, CGI или внешним API. Публикация содержит только HTML/CSS/JavaScript интерфейса и браузерные модули. В ней нет Python-коллектора, Shell/CGI, внутренних тестов или компонентов загрузчика. На мобильных устройствах сохраняется viewport width=device-width, initial-scale=1, viewport-fit=cover.
