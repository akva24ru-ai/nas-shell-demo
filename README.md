# NAS Shell 0.5 Demo

Публичная демонстрация интерфейса NAS Shell. Откройте GitHub Pages: https://akva24ru-ai.github.io/nas-shell-demo/.

Раздел «Оборудование» показывает только явно помеченные тестовые данные. Кнопка сканирования запускает локальный демонстрационный сценарий в браузере; запросов к NAS, CGI или внешнему API нет. Ручной импорт JSON остаётся доступен и выполняется локально.

Эта публикация содержит интерфейс и браузерный DEMO-адаптер. Она не включает диагностический Shell/Python-код, ARC-компоненты или данные реальных устройств. На мобильных устройствах задан viewport width=device-width, initial-scale=1, viewport-fit=cover.
